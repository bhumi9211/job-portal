# 💼 Job Portal Web App

A **MERN stack Job Portal application** with **real-time chat using WebSockets (Socket.IO)**.  
Connects students and professors/recruiters for job postings, applications, and instant messaging.

---

## 🚀 Features

- JWT-based authentication (Student & Professor roles)
- Job posting and application system
- Application status management (Accept / Waitlist / Reject)
- Real-time one-to-one chat (Socket.IO)
- Text & image messaging
- User profiles (skills, education, experience)
- Responsive UI

---

## 🛠️ Tech Stack

**Frontend:** React, Context API, Tailwind CSS, Socket.IO Client  
**Backend:** Node.js, Express.js, MongoDB, Mongoose, Socket.IO  
**Auth & Uploads:** JWT, Multer

---

## ⚙️ Setup

### Backend
cd server
npm install
npm run dev


### Frontend
cd client
npm install
npm run dev


---

## 🔌 Real-Time Chat
- Users join socket rooms using user ID
- Messages are delivered instantly without refresh
- Chat history stored in MongoDB
